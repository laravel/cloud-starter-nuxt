# Nuxt starter kit

A minimal Nuxt 4 app with server-side rendering, ready to deploy to [Laravel Cloud](https://laravel.com/cloud) and built as a starting point for coding agents.

```sh
npm install
npm run dev
```

The app runs on http://localhost:3000. Run the tests with `npm test`.

Agents: read [AGENTS.md](AGENTS.md) first.
